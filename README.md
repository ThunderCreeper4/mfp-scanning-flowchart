# About this Repository
This repository contains my documented findings over the years about various different findings relating to scanning errors on multiple different brands of Multifunction Devices. The information is arranged in a flow chart in the ordering that I would typically follow in diagnosis. See [Releases](https://github.com/ThunderCreeper4/mfp-scanning-flowchart/releases/latest) for a precompiled release or see the steps below for manual compilation from source.
# How to Compile
Using d2 you can compile files indivigually, to compile all files at once see appropriate installation steps below.
## Windows
> [!CAUTION]
> Still under development.
>`compile.bat` is not currently available yet

Dependencies: d2, git, go

To compile this repository on Windows run:
```
git clone https://github.com/ThunderCreeper4/mfp-scanning-flowchart
cd mfp-scanning-flowchart
compile.bat
cd compiled
```

No available yet

## Linux
Dependencies: d2, git, sed

To compile this repository on Linux run:
```
git clone https://github.com/ThunderCreeper4/mfp-scanning-flowchart
cd mfp-scanning-flowchart
./compile.sh
cd compiled
```
